# Chirper

A simple Twitter clone built with Laravel in just a couple of hours.

## Features

*   Create posts
*   View posts
*   Edit posts
*   Delete posts

## Installation

1.  Clone the repository
2.  Run `composer install`
3.  Run `npm install`
4.  Copy `.env.example` to `.env` and configure your database
5.  Run `php artisan migrate`
6.  Run `php artisan serve`

## Usage

1.  Create a new post by filling out the form on the homepage.
2.  Like a post by clicking the "Like" button.
